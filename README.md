## Featured Projects

**[FloodWatch](https://github.com/Gabby-127/floodwatch)**: Stormwater drain monitoring and community reporting platform for Jamaica, built by a team of three at the 2026 Intellibus Hackathon. I built the sensor-data, heartbeat, history and admin Lambda functions (DynamoDB storage, Amazon SES alerts) and set up Amazon Cognito authentication.
`TypeScript` `React` `AWS Lambda` `DynamoDB` `API Gateway` `Cognito` `SES` `SST`

**[EMG Gesture Classifier](https://github.com/Gabby-127/emg-gesture-classifier)**: Machine learning pipeline that classifies 6 hand gestures from 10-channel EMG signals (NinaPro DB1) using bandpass filtering, windowed feature extraction and a Random Forest, reaching 76.8% held-out test accuracy.
`Python` `scikit-learn` `NumPy` `SciPy` `Jupyter`
